## Communications + Intelligence Boundary

Reset provider identity remains separate from RMS provider identity:

- **Zoho + Netlify** = Reset communications/web operations
- **Google Workspace** = RMS human/company communication
- **Resend** = RMS transactional/system email
- **AOS / RMS Intelligence** = normalized cross-system intelligence only

Never place RMS Resend credentials, Google Workspace credentials, passwords, banking information, government identification, private contracts, unreleased masters, confidential rights data, private CreatorHub records, or automation credentials into public Discord channels or browser-delivered code.

Netlify intelligence relay credentials are server-side environment variables only. Browser code receives no ingress secret.
